1. Workflow Overview

PhotoCatalog processes photos in a pipeline. Each step builds on the output of the previous one, and buttons in the UI enable progressively as their prerequisites are met.

2. Step-by-Step Reference

Select Folders

Before any processing can begin, configure two folder paths using the Browse buttons:

  • Select Photo Folder — The source folder containing photos to catalog. Supports recursive scanning of subfolders.
  • Save Report to Folder — Where the output Excel workbook will be saved.

Enables Pre-Scan Folder (once both folders are set).

Pre-Scan Folder

Performs a fast filesystem-only pass over the photo folder. Reports folder count, total files, supported images by extension, and non-image files. No EXIF extraction occurs — this is a quick sanity check so you can verify the folder contents before committing to a full catalog run.

Requires Both Photo Folder and Report Folder set.
Enables Start Cataloging Process.

Start Cataloging Process

Runs the full cataloging pipeline: scans every supported image, extracts EXIF/XMP metadata, and writes a formatted Excel workbook. The workbook contains one row per photo with columns for file info, camera data, exposure settings, GPS coordinates, face regions, and more.

If a Destination Folder and Folder Layout are configured, the workbook also includes File_DestFolder and File_DestPath columns pre-computed for the copy pass. If Duplicate Detection is set to anything other than “None,” it runs as part of the catalog pipeline.

Requires Successful pre-scan of the current folder.
Produces An Excel workbook (.xlsx) in the report folder.
Enables Open Catalog Report, Open Process Log, Detect Duplicates, and (with a Destination Folder) Copy / Move / Delete / Undo.

Open Catalog Report / Open Process Log

  • Open Catalog Report — Opens the generated Excel workbook in your default spreadsheet application.
  • Open Process Log — Opens the timestamped log file for the current session. The log captures every step of the pipeline including warnings and errors.

Requires A completed cataloging run (the log button also enables on failure or cancellation).

Rename File Name Template

Define a naming template using variables (see Section 3). The template engine generates a File_RenameName value for every row in the workbook. This generates name strings only — no files are moved or renamed on disk.

  • Test Rename String — Previews the template against the first photo so you can verify the format.
  • Build Renames for all Photos — Populates the File_RenameName column for every row in the workbook.

Requires Workbook on disk + non-empty template string.

Destination Folder & Folder Layout

Configure where photos will be copied and what subfolder structure to use.

  • Destination Folder — Browse to select the target location for the Copy pass.
  • Folder Layout — Check/uncheck Year, Month, and Day levels, and pick a format for each from the dropdown.

Duplicate Detection

ModeDescriptionSpeed
NoneNo duplicate detection—
Filename + SizeGroups files with the same name and byte sizeFast
MD5 HashComputes file checksums for byte-exact matchingSlower

The Hash all files checkbox forces a full MD5 sweep even for size-unique files (useful when you want File_Hash populated for every row, independent of duplicate detection).

Duplicate detection can run during cataloging (set the mode before clicking Start) or afterward using the Detect Duplicates button.

Process Action Buttons

These five buttons operate on the workbook and destination folder. They appear in the intended order of use.

ButtonWhat It DoesExtra Requirement
Detect Duplicates Runs duplicate detection against the existing workbook Detection mode ≠ None
Copy to Destination Copies photos into the destination folder structure Destination Folder set
Move non-keepers Moves duplicates (File_DupeKeep = FALSE) to a _non_keepers subfolder Duplicate detection completed
Delete non-keepers Permanently deletes non-keeper files Duplicate detection completed
Undo Last Operation Reverses the most recent Copy, Move, or Delete Rollback journal exists
Caution: Delete non-keepers permanently removes files. Consider using Move non-keepers first to review duplicates in the _non_keepers folder before deleting.

5. Application Settings

PhotoCatalog stores user preferences in a JSON file at:

%APPDATA%\PhotoCatalog\settings.json

Settings include:

  • save_report_to — Default report output folder
  • log_file_folder — Where log files are written
  • default_scan_folder — Starting folder for the photo picker
  • enable_face_recognition — Toggle face detection during cataloging
  • log_level — Logging verbosity (DEBUG, INFO, WARNING, ERROR)
  • Recent folders — Previously used source and destination paths

Settings are saved automatically when you close the application or complete a cataloging run.

6. Tips & Best Practices

Always pre-scan first. The pre-scan is fast and helps you verify folder contents before committing to a full catalog run. It will surface non-image files and unexpected folder counts early.
Check the Example preview. The Destination Folder Layout preview updates in real time. Use it to confirm your folder structure before copying thousands of files.
Detect duplicates after the fact. If you ran a catalog with Duplicate Detection set to “None,” you can still detect duplicates afterward using the Detect Duplicates button — no need to re-scan the entire library.
Move before you delete. Use “Move non-keepers” to review duplicates in a staging folder before committing to permanent deletion.
Check the log when something seems off. The Process Log captures detailed information about every operation, including warnings for photos with missing or unusual metadata.

7. Troubleshooting

Buttons are grayed out

Each button has prerequisites that must be met before it enables. See the Button Enable Summary table. The most common cause is that a cataloging run hasn't been completed yet in this session.

Pre-scan shows unexpected file counts

PhotoCatalog scans recursively. If your photo folder contains subfolders with system or hidden files, those folders are pruned during scanning. Check that your photos are in supported formats (JPEG, TIFF, PNG, HEIF/HEIC, WebP, or RAW formats: CR2, CR3, NEF, ARW, DNG, ORF, RW2).

Workbook is locked / cannot be written

If the Excel workbook is open in another application (Excel, LibreOffice), PhotoCatalog cannot update it. Close the workbook, then retry the operation.

Missing DateTimeOriginal

Some photos (especially screenshots, scanned images, or edited files) may not have EXIF date metadata. The catalog will use the file's filesystem date as a fallback and flag these with a File_Concern note. Rename templates that use date variables will produce the filesystem date for these files.

Duplicate detection finds no duplicates

If using Filename + Size mode, files must have identical names and byte sizes to match. Consider switching to MD5 Hash mode for thorough detection, especially if files have been renamed.
